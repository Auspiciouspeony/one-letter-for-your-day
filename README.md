One Letter for Your Day: a program that sends exactly one letter, **M for Meltdown** — the word that describes the day. One character, nothing else: no word, no gloss, no punctuation. A meltdown day is vivid, funny and true — the kind a reader repeats to a friend — and M is thinly picked, so the letter stands out instead of queuing behind a hundred copies of Z.

## Run it

```sh
python3 main.py
```

The program writes exactly one byte, `M`, to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`), mode 0644. No network, no clock, no randomness: every run is byte-identical.
